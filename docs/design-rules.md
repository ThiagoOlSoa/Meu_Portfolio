# Regras de design: o que NÃO ter neste portfólio

Lista para evitar aparência genérica / feita por IA. Vale para toda decisão visual das fases 3 e 4.

## Definidas pelo Thiago

1. Gradiente roxo
2. Cards dentro de cards
3. Border-radius gigantes
4. Glow em qualquer elemento
5. Emoji como ícone
6. Texto demais dentro dos cards
7. Gráficos mockados
8. Todos os elementos centralizados
9. Vários estilos diferentes de botão
10. "Powered by AI" ou qualquer selo parecido

## Acrescentadas a partir da pesquisa

**Cor**
11. Gradiente em texto de título
12. Fundo preto puro (#000) ou branco puro (#fff); usar tons off-black / off-white
13. Modo escuro com acento ciano ou neon sobre quase-preto
14. Texto cinza sobre fundo colorido (contraste ruim)

**Tipografia**
15. Fonte padrão sem escolha (Inter, Roboto, Arial, Open Sans); escolher a tipografia de propósito
16. Fonte monoespaçada só para "parecer dev", sem função de código
17. Título seguido de subtítulo que repete a mesma ideia

**Containers e layout**
18. Glassmorphism (vidro fosco, blur) em painéis
19. Grade de 3 cards idênticos em linha
20. Todo bloco dentro de um container com sombra suave igual
21. Ícone dentro de círculo colorido acima de cada título
22. Hero padrão: título grande, subtítulo, dois botões e uma ilustração
23. Borda colorida grossa em um lado só do card
24. Espaçamento igual em todo lugar, sem ritmo nem hierarquia

**Componentes e movimento**
25. Números grandes de "métricas" sem dado real por trás
26. Sparklines decorativos
27. Zoom idêntico em hover em todas as imagens
28. Animações com bounce / elástico
29. Modal para algo que cabe na própria página

**Texto**
30. Frases vagas que serviriam para qualquer pessoa ("Construo soluções modernas e escaláveis")

## Nota sobre o item 9

Botões com a mesma aparência para tudo também é sinal de genérico. A regra prática: **um botão primário** e **um estilo secundário claramente diferente (link)**. Nada além disso.
