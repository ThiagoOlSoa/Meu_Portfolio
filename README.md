# Meu Portfólio

Portfólio de Thiago Soares feito com React + Vite, publicado no GitHub Pages:
https://thiagoolsoa.github.io/Meu_Portfolio/

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

O deploy é automático a cada push na `main` (GitHub Actions).
Os projetos antigos em HTML/CSS ficam em `public/` e são servidos como estão.
